# Python Finance Lab

O python-finance-lab é um repositório dedicado ao desenvolvimento de estudos, análises e experimentações em Python aplicadas ao mercado financeiro.

O objetivo deste projeto é reunir notebooks, scripts e aplicações que explorem dados financeiros, indicadores econômicos, modelos estatísticos, econométricos e técnicas de Ciência de Dados, utilizando bases públicas e ferramentas amplamente empregadas pelo mercado.

Os estudos possuem caráter educacional, analítico e experimental, podendo abranger diferentes temas relacionados às finanças, economia e investimentos.

---

## Objetivos

- Desenvolver análises quantitativas utilizando Python;
- Explorar dados financeiros e macroeconômicos;
- Aplicar modelos estatísticos e econométricos;
- Construir visualizações para apoio à tomada de decisão;
- Documentar estudos e experimentações voltados ao mercado financeiro.

---

## Temas abordados

Este repositório poderá conter estudos relacionados a:

- Mercado de ações
- Setor bancário
- Empresas do setor de petróleo e energia
- Commodities
- ETFs
- Fundos Imobiliários (FIIs)
- Criptomoedas
- Carteiras de investimentos
- Indicadores macroeconômicos
- Taxa Selic
- Inflação
- Câmbio
- Séries temporais
- Econometria
- Machine Learning aplicado às finanças
